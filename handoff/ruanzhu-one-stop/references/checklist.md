# 软著申请 · 材料清单与流程检查表

> 配合 SKILL.md 主流程使用。提交前逐条打勾。

## A. 材料清单

- [ ] **软件著作权登记申请表**（在线填报，打印带条形码签章页，签章后扫描 PDF 上传；不得电子签名替代）
- [ ] **源程序鉴别材料**（CodeDoc 生成）：前后各连续 30 页 / 共 60 页；不足 60 页交全部；每页 ≥ 50 行；页眉=软件全称+版本号；首页开头、末页结尾
- [ ] **文档鉴别材料**（用户手册/设计说明书，见 manual-template.md）：前后各连续 30 页；每页 ≥ 30 行；建议 ≥ 15 页、图文并茂
- [ ] **身份证明文件**：企业营业执照（统一社会信用代码）/ 个人身份证
- [ ] **权利归属证明**（视情况）：委托/合作合同、项目任务书、转让/继承/承受证明

## B. 一致性核对（高频补正点）

- [ ] 软件名称 + 版本号：申请表 / 代码页眉 / 文档页眉 **三处完全一致**（带不带 V 以申请表为准）
- [ ] 源程序量（行数）：申请表填报 = CodeDoc 统计 = 说明书描述
- [ ] 说明书功能 ↔ 源代码实现 对应，无矛盾、无照搬
- [ ] 说明书截图 ↔ 软件实际界面 一致

## C. 提交规范

- [ ] 材料为 PDF，单文件 ≤ 10MB
- [ ] 文件命名：`软件名称_材料类型_页码`，如 `智能排课系统_源程序_01-30.pdf`
- [ ] 敏感信息已脱敏（CodeDoc 自动 / 或例外交存黑线覆盖 ≤50%）
- [ ] 通过中国版权保护中心（ccopyright.com.cn）网上提交

## D. 时限提醒

- [ ] 收到补正通知后 **30 个工作日内** 完成补正，逾期视为撤回
- [ ] 全程以中国版权保护中心最新规定为准（规则可能调整）
